# ADR-0001 実装基盤の技術選定

- 状態: 採用
- 決定日: 2026年8月10日
- 対象段階: 実装ロードマップ 段階0

## 背景

最小実装に着手するため、使用言語、ランタイム、プロジェクト構成、品質確認方法および設計判断記録の保存場所を決める必要がある。

## 決定

- 使用言語とランタイムは Python 3.11 以上とする。
- 段階0では外部パッケージを追加せず、標準ライブラリだけを使用する。
- 実装は `src/yamicha`、テストは `tests`、検査処理は `scripts` に置く。
- 設計判断記録は `docs/03_design/decisions` に置く。
- 品質ゲートは `python scripts/quality.py` で一括実行する。
- CI は同じ品質ゲートを実行し、ローカルと検証内容を一致させる。

## 理由

Python 3.11 は現在の開発環境で利用でき、外部依存なしでビルド、単体テスト、UTF-8検査、依存方向検査および構造化ログを開始できる。技術選定を生命構造へ持ち込まず、論理責務をパッケージ境界へ写像できる。

## 影響

- 段階0はネットワーク接続なしで再現できる。
- 外部AI、データベース、UIおよび配備先は決定しない。
- 将来ランタイムを交換する場合も、上位文書の責務、所有情報、情報経路および適合試験を維持する。
