# Yamicha 記録・記憶・経験 Version 0.1

本書は、実装ロードマップ段階6における生命循環記録、記憶候補、経験候補、所有者による候補評価および再評価の実装境界を記録する。

## 1. 記録から候補評価までの経路

```text
検証済み入力
  → 判断と核の最終確定
  → 言葉、核の表現確認、対話出力境界
  → 核が生命循環記録を作成
  → 判断が記録を根拠に記憶候補と経験候補を作成
  → 核が候補を指定された所有者へ配送
  → 記憶が自らの所有領域で採用・保留・統合・不採用を決定
  → 後続結果が得られた場合は判断が経験候補を再評価
  → 核が再評価済み候補を記憶へ配送
```

段階6の保存先はプロセス内メモリだけである。DB、ファイル、外部サービスへの永続化は行わない。

## 2. 記録

核は、完了した一つの生命循環を `LifecycleRecord` として保持する。記録は次の4種類の `RecordEntry` を持つ。

| 種類 | 発行元 | 記録する事実 |
|---|---|---|
| `EVENT` | 感覚 | 検証済み文字事象を受領したこと |
| `JUDGMENT` | 判断 | 核が確定した判断方向 |
| `EXPRESSION` | 言葉 | 作成した表現方法と表現成果への参照 |
| `RESULT` | 保護境界 | 対話出力が解放・沈黙・遮断のどれになったか |

各項目は、項目ID、生命循環ID、発行元、正本参照、要約、時刻、確からしさおよびスキーマ版を持つ。

`RESULT` は対話出力境界の結果であり、相手が理解したこと、外部操作が成功したこと、世界に意図した効果が生じたことを意味しない。

## 3. 記録、記憶、経験候補の分離

次の型を別の意味型として実装する。

| 概念 | 型 | 意味 |
|---|---|---|
| 記録 | `LifecycleRecord` / `RecordEntry` | 起きた処理を追跡する事実記録 |
| 記憶候補 | `RetentionCandidate` (`MEMORY`) | 現在から参照する意味として保持する提案 |
| 経験候補 | `RetentionCandidate` (`EXPERIENCE`) | 後続結果によって意味を持つ可能性がある提案 |
| 記憶項目 | `MemoryItem` | Memoryが候補を評価し、自らの所有領域へ採用した情報 |

記録を作っただけでは、記憶項目も経験も成立しない。経験候補を保存しただけでも経験にはならない。

## 4. 判断と所有者の分離

判断は `LifecycleRecord` を参照し、次の候補を作る。

- 確定した判断経路を後から参照するための記憶候補
- 対話出力の後続結果を待つ経験候補

判断はMemoryの内部情報を直接更新しない。核は候補を配送するだけで、採否や記憶内容を決めない。Memoryだけが候補を検証し、自らの所有領域を更新する。

## 5. 候補評価

Memoryは候補を次の状態へ評価する。

| 状態 | 条件 |
|---|---|
| `ADOPTED` | 根拠と確からしさがあり、新しい記憶項目として採用可能 |
| `HELD` | 経験候補に相手または世界の後続結果がなく、意味を確定できない |
| `INTEGRATED` | 同じ意味の既存記憶があり、由来と候補を既存項目へ統合 |
| `REJECTED` | 所有者が異なる、または候補版が古い・重複している |

採用または統合された `MemoryItem` は、更新理由、候補ID、記録項目ID、作成・更新時刻、確からしさおよび版を保持する。

## 6. 経験候補の再評価

通常の対話出力直後は、相手がどう受け取ったかを観測していない。このため経験候補は `UNKNOWN` の確からしさで保留し、再評価条件を「後続の人間または世界の結果を観測する」とする。

後続結果が記録された場合、判断はその記録を追加根拠として経験候補の意味、版および確からしさを再評価する。再評価済み候補も核を経てMemoryへ渡し、Memoryが所有者として改めて採否を決める。

段階6で採用するのは経験候補の根拠・意味付けを持つ記憶項目であり、人格、全体規則または成長変更ではない。経験による振る舞い変更は後続段階の統治対象とする。

## 7. 現在の制限

- 保存はメモリ内だけで、終了すると失われる
- 参照は記憶項目IDによる単純な関連付けで、高度な意味検索は行わない
- 記憶参照は判断材料へ渡るが、現在の定型表現は過去の意味から自然な文章を生成しない
- 人間の後続反応を自動的に元の経験候補へ対応付ける処理は未実装
- 忘却、非活性化、永続化、復元は段階7以降で実装する
