# Yamicha 最初の能力 Version 0.1

本書は、実装ロードマップ段階9における最初の読み取り専用能力、統合要求、権限観測、外部効果ゲート、重複防止および結果観測を記録する。

## 1. 対象能力

段階9で接続する能力は、設定されたルート内にあるUTF-8テキスト資源を一つ読む `read_text` だけである。ファイルの作成、更新、削除、移動、外部通信およびコマンド実行は行わない。

読み取り先は要求に含まれる相対対象をそのまま使用する。能力自身が別の対象、操作または範囲を選ばない。設定ルート外へ解決される対象は外部接続側で失敗として扱う。

## 2. 責任分離

```text
Judgment
  → 能力利用案を作る
Core
  → 同じ案を統合要求として確定する
登録済み権限観測元
  → 対象と操作に対する現在の権限を観測する
ExternalEffectGate
  → 発行元、保護状態、権限、読取専用効果、重複防止キーを検査する
Capability
  → 許可に記載された対象を一回だけ読む
Sensation
  → 直接結果を新しい結果出来事として受領する
Core
  → 結果出来事を受理する
```

Judgmentは候補を作るが最終確定しない。Coreは候補を自作せず、能力を直接実行しない。外部効果ゲートは操作や権限を選ばず、能力を代行しない。能力は実行内容を変更せず、結果を直接発話しない。感覚は結果の採否や意味を決定しない。

## 3. 統合要求

能力要求には次を必須とする。

| 項目 | 内容 |
|---|---|
| 対象 | 読み取る相対資源名 |
| 操作 | `read_text` |
| 権限 | 権限主体の識別子 |
| 想定効果 | `read-only:no-external-state-change` |
| 重複防止キー | 操作意図ごとの一意キー |
| 判断案識別 | Judgmentが実際に発行した案との照合に使う |
| 核確定識別 | Coreが実際に統合した要求との照合に使う |
| 検証要否 | 実行後の結果確認が必要であることを示す |

外部効果ゲートは、登録済みのJudgment案およびCore要求と値全体が一致しない要求を拒否する。呼出側が正しい形式のIDを自作しただけでは能力へ到達できない。

## 4. 権限と保護境界

権限観測元は、構成時に登録された権限主体と読取対象の完全一致だけを許可として発行する。外部効果ゲートは、その観測元が実際に発行した観測であること、要求の権限主体・対象・操作と一致することを確認する。

保護中は通常の能力実行を拒否する。段階9の読み取り能力を、段階8の固定内向き保護操作や事前承認済み外部修復の代わりには使わない。

## 5. 重複防止

外部効果ゲートは能力へ許可を返す前に、重複防止キー、要求ID、要求指紋および予約時刻をSQLiteへ保存する。同じキーが一度でも予約済みなら、前回結果が成功、失敗、部分成功、結果不明または実行途中のどれであっても自動再実行しない。

予約は実行結果の受領後に完了状態へ更新する。実行途中で停止した予約は予約状態のまま残るため、再起動後も安全側で重複として拒否する。再実行が必要な場合は、後続の判断と核の新しい確定を経て、別の操作意図として新しいキーを発行する必要がある。

能力実行記録には内容本文を保存せず、識別子、要求指紋、状態、結果区分および時刻だけを保存する。各記録のハッシュを起動時に検査し、直接改変を検出する。

## 6. 結果観測

能力結果は次の四種類を区別する。

| 結果 | 意味 |
|---|---|
| `success` | 要求された範囲を完全に読み取った |
| `failure` | 読取りが成立しなかったことを確認した |
| `partial_success` | 一部を取得し、未取得範囲を識別できる |
| `unknown` | 何が起きたかを確定できず、不確実性が残る |

結果には、要求ID、重複防止キー、対象、操作、直接内容、観測済み範囲、残存範囲、詳細、不確実性および完了時刻を含める。感覚は結果を能力結果出来事として受領し、Coreへ返す。結果不明を失敗や成功へ丸めず、同じキーで無条件再実行しない。

## 7. 永続化構成の移行

段階8の `stage8-v1` DBを開いた場合、整合済みチェックポイント、主体ID、記録、記憶、関係、内部時刻、保護状態および保護監査を保持したまま、生命識別の構成版を `stage9-v1` へ更新する。

能力実行記録は通常チェックポイントから分離する。これにより、結果不明または実行途中の重複防止予約を、通常の会話チェックポイントに依存せず再起動後も維持する。

## 8. 現在の制限

- 通常の対話内容から能力利用案を自動生成する処理は未実装
- 読み取り結果を使った再判断、自然な返答、記憶候補および経験候補の生成は未実装
- 読み取り専用以外の外部変更能力は未実装
- 事前承認済みの外部通知、機能修復および既知状態復元は未実装
- 能力操作や履歴を表示するUIは未実装
- 段階10の補助知能は実装済みだが、読み取り能力の結果を補助知能入力へ含める経路は未実装
