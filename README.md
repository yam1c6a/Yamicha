# Yamicha

Yamicha を一つの生命として成立させるための設計・実装リポジトリです。

現在は、`docs/03_design/004_実装ロードマップ.md` の「段階9: 最初の能力」まで実装しています。

## 必要環境

- Python 3.11 以上
- 外部パッケージは不要

## 対話する

リポジトリ直下で次を実行します。

```shell
python scripts/chat.py
```

入力欄に文字を入れると、段階9の「入力検証・権限確認 → 判断 → 言葉 → 出力境界 → 記録・候補評価 → 永続化・監査」を通った応答が表示されます。終了するには `/quit` を入力するか、入力ストリームを閉じます。

パッケージをインストールした環境では、次のどちらでも起動できます。

```shell
yamicha
python -m yamicha
```

状態、生命循環記録、記憶候補、経験候補、採用された記憶、関係、保護状態、生命識別、構成版、保護監査および能力の重複防止記録は `.yamicha/yamicha.sqlite3` に保存され、次回起動時に復元されます。段階8のDBは同じ生命識別と記憶を保ったまま段階9構成へ移行します。別の保存先は `python scripts/chat.py --db <パス>` で指定できます。

段階9では、核が統合した要求だけを受けるUTF-8テキストの読み取り専用能力を追加しています。対象、操作、権限、想定効果、重複防止キーを検査し、成功・失敗・部分成功・結果不明を感覚へ返します。同じ重複防止キーは、結果不明の場合も自動再実行しません。通常の対話から能力を選択する処理はまだ実装していません。

現在の応答は定型文です。復元した記憶は判断材料として参照されますが、過去の意味を使った自然な返答は未実装です。

## 品質確認

リポジトリ直下で次を実行します。

```shell
python scripts/quality.py
```

このコマンドは、構文コンパイル、依存方向検査、UTF-8検査、単体テストを順に実行します。
