# Yamicha

Yamicha を一つの生命として成立させるための設計・実装リポジトリです。

現在は、`docs/03_design/004_実装ロードマップ.md` の「段階6: 記録・記憶・経験」まで実装しています。

## 必要環境

- Python 3.11 以上
- 外部パッケージは不要

## 対話する

リポジトリ直下で次を実行します。

```shell
python scripts/chat.py
```

入力欄に文字を入れると、段階6の「入力 → 判断 → 言葉 → 出力境界 → 記録・候補評価」を通った応答が表示されます。終了するには `/quit` を入力するか、入力ストリームを閉じます。

パッケージをインストールした環境では、次のどちらでも起動できます。

```shell
yamicha
python -m yamicha
```

現在の応答は定型文です。起動中は生命循環記録と採用された記憶参照を保持しますが、過去の意味を使った自然な返答は未実装です。永続化と再起動後の復元も未実装のため、コンソールを終了すると記録と記憶は失われます。

## 品質確認

リポジトリ直下で次を実行します。

```shell
python scripts/quality.py
```

このコマンドは、構文コンパイル、依存方向検査、UTF-8検査、単体テストを順に実行します。
